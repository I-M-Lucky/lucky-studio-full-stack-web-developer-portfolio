Lucky Verma (Lokesh) – single-page portfolio
Open index.html (or any static host). Everything is on one page: Home, Skills, Projects, Contact.
Edit content in script.js (DATA section at the top):
  CONTACT_EMAIL / WHATSAPP_NUMBER / LINKEDIN_URL  -> contact details and links
  certificates   -> certificate cards (open in a small popup)
  skillGroups    -> skill cards (icons are inline SVGs in the ICONS object)
  projects       -> project cards (title, tag, url, img, text)
